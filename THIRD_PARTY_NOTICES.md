# Third-party executable

The Windows and macOS installers contain an unmodified mihomo v1.19.32
executable, maintained by the MetaCubeX contributors. It runs as a separate
process and is licensed under GNU GPL version 3.

The installer includes `chatgpt-core/LICENSE` and the corresponding source
archive `chatgpt-core/mihomo-source-v1.19.32.zip`. The upstream release is at
https://github.com/MetaCubeX/mihomo/releases/tag/v1.19.32.

The proxy executable is separate from the jokerdeck client. The client does
not imply that network access grants any OpenAI account or plugin entitlement.
